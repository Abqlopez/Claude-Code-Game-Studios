# Catch of the Day

| | |
|---|---|
| Ingredients | any 1 fish (your cheapest one is used) |
| Station | Grill |
| Kind | mixed (Humans, Octofolk, Crabfolk eat it) |
| Price | $10 (fixed) |
| Unlock | always known, on the starting menu |

**Why:** guests should be able to order from what you actually caught. A morning of squid with no squid dish on the menu still makes money.

**Trade-off:** it sells below almost every named dish, and Sailors and Crabfolk (who pick the cheapest dish) will order it when it is on the menu. Leave it off when your named dishes are well stocked.

**Rules:**
- Uses the cheapest fish in the tank, so it never eats a Dragon Koi unless that is all you have.
- A single fish with no sides that also matches a named dish (1 Sardine → Grilled Sardine) counts as the named dish, in the Kitchen lab and on the cutting board.
- Old saves get it added to their known recipes when they load.
