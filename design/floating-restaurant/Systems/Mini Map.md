# Mini map (v4)
A round map in the top-right corner while you fish, 80 units across each way, north up.
- **White dots** = fishing spots. It never says which fish.
- **Orange squares** = your crab traps; **green** when ready.
- **House** = the restaurant; pinned to the edge, pointing home, when it is far.
- **Orange arrow** = you, pointing the way the skiff faces.
