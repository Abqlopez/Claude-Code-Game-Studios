# Customizing in 3D (plan)
Every v3 customization carries into 3D. The boat will be built from a layout list (what goes where), so changing that list changes the boat.

| Feature | How it works in 3D |
|---|---|
| Theme | Swaps colours and materials: hull, trim, awnings, tablecloths, chairs. Beach Shack and Pirate Ship each get their own set. |
| Paint | Recolours the hull stripe and trim live. |
| Decor | Each decor item is a 3D model with set spots: lanterns, plants, string lights, bunting, rugs, aquarium, sign. Buying one makes it appear. |
| Floor plan | Build mode: the camera tilts straight down, a grid appears, you pick up tables, stations and decor and drop them on grid cells. Pieces cannot block doors or overlap. |
| Stations and staff | Host stands, dish pits and cook stations placed the same way (they already exist at fixed spots). |
| Bigger boat | Table upgrades lengthen the dining room; the kitchen and bedroom stay put. |

## Status (v4.1)
Built in [[v4.1]]: theme, paint, decor, name, sections and a table-only build mode. The bigger boat became a dock patio; kitchen stations and decor are not movable yet.
